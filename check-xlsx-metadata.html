Check metadata in an Excel XLSX file

An Excel workbook can carry document properties that are not visible in cells, charts or formulas.

Quick answer

XLSX files can store core, application and custom document properties such as Author, Last Modified By, Company, Manager, dates and custom fields. Inspect those properties before sharing a workbook outside your team or organization.

Metadata fields to review

Field / areaWhat it isWhy it matters
Author / CreatorCore propertyCan identify the person or account associated with the workbook.
Last Modified ByCore propertyCan reveal the most recent editor.
Company / ManagerApplication propertiesCan expose organization context.
Custom propertiesWorkbook-defined metadataMay contain project names, internal IDs or workflow labels.

Quick questions

Can Excel files contain author metadata?

Yes. XLSX files can contain creator and other document properties even when the workbook itself shows no author name.

Does cleaning metadata change formulas or cells?

Metadata cleanup is separate from visible workbook content. Always verify the generated copy and review formulas, comments and cell values independently.
