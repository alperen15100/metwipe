WORD · LAST MODIFIED BY

Remove Last Modified By metadata from Word

The Last Modified By property can reveal the editor or account name associated with a Word file even when that information is not visible on the page.

Quick answer

MetWipe checks supported DOCX core properties, including Last Modified By. The cleaner works on a separate copy and verifies the rebuilt DOCX so you can review the distribution file rather than assuming the field is gone.

Clean Word Metadata

Editor identity

Last Modified By can expose a username or profile name used while editing.

Pair with Author review

Author and Last Modified By are separate properties, so check both before distribution.

Verify the copy

Re-open the output after cleaning and confirm the supported properties no longer contain the information you intended to remove.

How to do it safely

  1. Open the Word metadata remover.
  2. Select the DOCX and inspect supported properties.
  3. Create a cleaned copy when Last Modified By should not be shared.
  4. Verify the output and review the visible document separately.

What this does not cover

This does not erase visible editor names, comments, tracked revisions or collaboration content that remains inside the document.
