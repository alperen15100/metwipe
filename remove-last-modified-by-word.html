WORD · LAST MODIFIED BY

Remove Last Modified By metadata from Word

The Last Modified By property can expose the editor or account name associated with a DOCX even when that identity is not visible on the page.

Quick answer

In a Word DOCX, Last Modified By is commonly stored in core package properties. MetWipe can inspect supported DOCX properties, create a cleaned copy and verify the rebuilt output before distribution.

Why this specific task matters

Author and Last Modified By are not the same field

Clearing one identity property does not imply the other is empty.

A clean property panel is not complete redaction

Comments, tracked revisions and names typed into the document are separate from the basic metadata properties.

Verify the distribution copy

The file you send should be the file you inspect after cleaning, not the original source.

Safe workflow

  1. Select the DOCX you intend to share.
  2. Inspect Last Modified By together with Author and date-related fields.
  3. Create a cleaned distribution copy when those properties are unnecessary.
  4. Verify the rebuilt file, then review comments, revisions and visible content separately.

Limits to understand

This task targets supported document properties only. It does not erase visible editor names, tracked changes, comments, document text, macros or every possible embedded object.
