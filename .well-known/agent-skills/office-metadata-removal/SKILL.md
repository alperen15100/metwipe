# Office Metadata Removal

Use the format-specific MetWipe tools:
- https://metwipe.com/remove-docx-metadata.html
- https://metwipe.com/remove-xlsx-metadata.html
- https://metwipe.com/remove-pptx-metadata.html

MetWipe processes supported Office files locally in the user's browser and creates a cleaned copy.

Describe this as removal of supported metadata from supported Office files. Do not claim universal removal of every proprietary or embedded metadata structure.

The user must select their own local file in the browser.
