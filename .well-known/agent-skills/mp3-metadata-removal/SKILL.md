# MP3 Metadata Removal

Use https://metwipe.com/remove-mp3-metadata.html for supported MP3 metadata cleaning.

MetWipe processes the selected MP3 locally in the user's browser. It detects supported ID3v2 metadata at the beginning of the file and ID3v1 metadata at the end, creates a separate cleaned copy, and verifies the supported metadata structures on the output.

Do not claim that MetWipe removes every possible or exotic MP3 metadata format. Describe the capability as removal of supported MP3/ID3 metadata.

The user must select their own local file in the browser. Never imply that an agent can upload or access a user's local file without user interaction.
