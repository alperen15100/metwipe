Remove EXIF metadata from iPhone photos

iPhone photos can contain capture details such as date, device information and, when location services recorded it, GPS metadata. Before posting or sending a photo, you can inspect the file and create a cleaned copy with MetWipe.

What should you check?

Look for GPS coordinates, capture time, camera or device details and other descriptive metadata. Not every iPhone image contains every field: screenshots, edited images and files downloaded from other services can differ.

How to remove metadata before sharing

  1. Export or save the photo as a supported JPG/JPEG file.
  2. Open the MetWipe scanner and select the file.
  3. Review the metadata reported by the scanner.
  4. Create the cleaned copy and download it.
  5. Scan the downloaded copy again before sharing it.

Local processing

For supported files, MetWipe performs its inspection and cleanup in your browser. Your original file is not overwritten; the cleaner creates a separate copy.

Metadata removal is not visual redaction

Removing EXIF does not remove information visible inside the image itself. Street signs, faces, house numbers, reflections and recognizable landmarks can still reveal information. Crop, blur or redact visible details separately when needed.

Important: iPhone photos are not always JPEG files

Some iPhone photos are stored or exported as HEIC/HEIF rather than JPG/JPEG. The current MetWipe JPEG EXIF workflow applies to supported JPG/JPEG files; it does not claim native HEIC cleanup. Check the file format first. If you create a JPEG copy for sharing, inspect that exact copy because conversion or editing can change which metadata fields are present.

Why inspect the final sharing copy?

The metadata in an original photo, an edited photo and an exported copy can differ. For that reason, the useful privacy check is not only the source image: inspect the exact file you plan to upload, message or publish. If you clean it, verify the downloaded cleaned copy before sharing.

iPhone metadata vs visible information

Even after supported EXIF fields are removed, the picture itself can reveal a location or identity through signs, faces, screens, documents, reflections and recognizable landmarks. File metadata cleanup is one layer of a sharing review, not a substitute for visual redaction.
