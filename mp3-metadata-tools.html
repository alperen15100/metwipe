MP3 metadata and copyright are not the same thing

A tag can contain text that mentions copyright or ownership, but deleting supported metadata does not transfer rights, cancel a license or make copyrighted audio free to reuse. Metadata cleanup changes file metadata; copyright ownership and licensing are separate legal questions.

Which MP3 metadata tool should you use?

Use the checker when you need to know whether the file contains supported title, artist, album, comment, artwork or other tag data. Use the remover when you already intend to create a cleaner distribution copy. Use the album-art workflow when embedded artwork is the specific concern rather than all supported tags.

For a file you plan to publish, the strongest workflow is inspect the MP3 → clean a copy → inspect that downloaded copy again. If you need field-level context first, use the metadata field reference.
