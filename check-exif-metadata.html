PHOTO · EXIF CHECK

Check EXIF metadata in a photo

Photos can carry camera, time and location metadata that is invisible in the image itself. Inspect the file before you post, send or publish it.

Quick answer

EXIF and related photo metadata can reveal camera details, capture settings, timestamps and—when present—GPS coordinates. MetWipe lets you inspect supported fields locally before deciding whether to clean the photo.

Check Photo Metadata

Camera details

Make, model and capture settings can identify the device or shooting setup.

Time information

Timestamps can reveal when a photo was created or processed.

GPS coordinates

Location fields can disclose where a photo was captured when GPS metadata is present.

How to do it safely

  1. Open the EXIF tool.
  2. Choose the image you want to inspect.
  3. Review supported camera, time and GPS fields.
  4. If needed, create a cleaned copy and verify it before sharing.

What this does not cover

Metadata inspection does not detect private information visible in the pixels, such as faces, addresses, badges, screens or documents in the background.
