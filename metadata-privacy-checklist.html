METWIPE PRIVACY GUIDE

Metadata Privacy Checklist

Different file formats store different kinds of metadata. A repeatable checklist helps reduce accidental information disclosure.

Identify the file type

Photos, audio and office documents use different metadata structures. Choose a tool designed for the actual format.

Inspect before cleaning

Understanding what is present helps you decide what should be removed and what should be preserved.

Prioritize sensitive information

GPS coordinates, author fields, comments and identifying information deserve extra review.

Clean a copy

Preserve your original if metadata has archival or workflow value.

Verify the result

Inspect the cleaned output again and remember that metadata removal cannot hide information contained in visible, audible or written content.

Use MetWipe

Inspect and clean supported metadata locally in your browser. MetWipe is designed so supported file processing can happen on your device rather than requiring an application-server upload.
