MP3 METADATA CHECK

Check MP3 metadata before you share

See whether an MP3 carries supported tag structures before you send, publish or archive it. The file stays in your browser during the MetWipe workflow.

Quick answer

MP3 metadata can include title, artist, album, comments, artwork and other tag data that is separate from the audio stream. Inspect the file first; if the metadata is not needed, open the MP3 cleaner and verify the cleaned copy afterward.

Check MP3 Metadata

ID3 tags

Look for supported ID3 structures that can carry common track information and embedded fields.

Artwork & comments

Cover art and comments can live inside metadata rather than the audible content.

Other tag structures

MetWipe also documents support for APEv2 and Lyrics3 structures within the current MP3 workflow.

How to do it safely

  1. Open the MP3 metadata tool.
  2. Choose the MP3 copy you plan to share.
  3. Review the supported metadata structures detected.
  4. Clean only if needed, then re-open the output to verify the result.

What this does not cover

Metadata inspection does not analyze spoken words, lyrics inside the audio, ownership rights or every possible proprietary tag. Review the audible content separately.
