Supported formats and verification limits

MetWipe reads a selected file in your browser and creates a separate cleaned copy. Verification means that the same supported metadata checks are run on the output. It is not an independent forensic audit or a guarantee that no personal information remains.

FormatCleanup scopeImportant limits
JPEGAPP1–APP15 and comment segmentsEncoded JPEG scan data is retained without a new image-compression pass. Visible faces, addresses and text remain.
PNGtEXt, zTXt, iTXt, eXIf and tIME chunksCore image chunks are retained. Other private/unknown chunks and visible content are outside the check.
WebPEXIF and XMP chunksThe cleaner retains encoded image chunks. Other RIFF chunks are outside its metadata-removal scope.
MP3Supported ID3v1, ID3v2, APEv2 and Lyrics3 structuresAudio is not transcribed or redacted. Support and verification vary by tag structure; see the MP3 guide for current tested limits.
WAVLIST, bext, iXML, ID3, cart and DISP chunksAudio data is retained; information spoken in it remains. LIST removal can also remove useful descriptive organization.
DOCX / XLSX / PPTXSupported core properties, plus Company and Manager in application propertiesComments, revisions, cell values, slides, notes, custom properties, macros and embedded media are not a complete redaction target. Browser compression support is required.

What does “verified” establish?

The output is reopened by the format-specific parser. A successful supported check establishes only that its targeted fields or blocks were not detected. The parser and cleaner share implementation assumptions, so agreement between them is not proof of universal anonymity. Open the downloaded copy in another compatible viewer and inspect its visible content before sharing.

Unsupported and damaged files

Renaming an extension does not convert a file. Older DOC/XLS/PPT, encrypted Office files, PDF, HEIC and video do not have a supported cleanup workflow here. Unusual or malformed structures can fail. Keep your original; do not interpret an error or an incomplete result as success. Large files can exceed your browser memory even if their extension is supported.

Batch files and receipts

Batch cleaning processes supported files locally and builds a ZIP. The receipt describes supported checks, not identity removal. Keep it private if filenames reveal information. If a batch fails, review the error and retry a smaller group; verify the downloaded contents before deleting any originals.

Reproduce a basic check

  1. Use a non-sensitive test file with a known metadata value.
  2. Record what the scanner detects before cleaning.
  3. Clean and download the copy, then select that output for another scan.
  4. Check that the targeted value is absent and that a separate viewer still opens the file correctly.

Implementation reference: MetWipe source code. The scope above was checked against the code on 13 September 2026. Report a reproducible discrepancy.
