What “clean” means in MetWipe

MetWipe reports on the metadata structures supported by the current format workflow. A successful supported-metadata verification is not a promise that a file contains no identifying information. Filenames, visible document text, tracked changes, comments, embedded content, spoken audio, image pixels and proprietary metadata outside the documented scope can still reveal information.

How to use this metadata reference

Start with the file format, identify the metadata structure that may contain the information you care about, then follow the matching checker before deciding whether cleanup is needed. The reference links to maintained format-specific workflows instead of treating EXIF, ID3, RIFF and OOXML as interchangeable metadata systems.
