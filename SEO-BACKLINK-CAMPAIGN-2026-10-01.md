## Canonical submission copy

**Product name:** MetWipe

**Website:** https://metwipe.com/

**GitHub:** https://github.com/alperen15100/metwipe

**Tagline:** Free local metadata remover for photos, audio and Office files.

**Short description:** MetWipe is a browser-based privacy utility that checks, removes and verifies supported metadata from JPEG/EXIF, PNG, WebP, MP3, WAV and Office DOCX/XLSX/PPTX files. Supported processing happens locally in the browser; files are not uploaded to a MetWipe application server for processing.

**Long description:** MetWipe helps users inspect and clean privacy-relevant metadata before sharing files. It provides format-specific checkers and cleaners for photo EXIF/GPS metadata, PNG/WebP metadata, MP3 tags and artwork, WAV RIFF metadata, and Office document properties. The workflow is built around Inspect → Clean → Verify, keeping the original file untouched and creating a separate cleaned copy. MetWipe documents exact format limits and does not claim that metadata cleanup is the same as full redaction.

## Skip / do not pursue

Do not pitch MetWipe to lists whose inclusion rules require no advertising/tracking scripts. MetWipe uses AdSense, even though file processing itself is local.

Examples to avoid unless site monetization changes:
- pluja/awesome-privacy

### Reciprocal-badge-first directories
Do not add permanent footer badges solely to obtain a backlink unless the directory is strategically valuable. Avoid degrading the site or creating obvious reciprocal-link patterns.

### AI-only directories
MetWipe is not an AI product. Do not submit to AI-only directories just because they accept free listings.
