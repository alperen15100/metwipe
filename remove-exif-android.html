Remove EXIF metadata from Android photos

Photos created on Android phones may contain EXIF information including capture time, camera details and GPS coordinates when location tagging is enabled. MetWipe lets you inspect supported JPEG files and create a cleaned copy before sharing.

Android metadata varies by device

Metadata depends on the phone, camera app, settings and any editing or messaging apps the image passed through. A file may contain GPS data, other EXIF fields, both or neither, so inspect the actual file rather than assuming.

Clean a supported Android JPEG

  1. Select the JPG/JPEG you plan to share.
  2. Open the MetWipe scanner in your browser.
  3. Review the fields found in the file.
  4. Create and save a cleaned copy.
  5. Re-scan the downloaded copy to verify the result.

Why verify?

A successful download alone is not proof that every privacy-relevant clue is gone. MetWipe's workflow encourages checking the generated copy again, and visible information inside the pixels remains outside metadata cleanup.

Before uploading to social media

Check both metadata and the picture itself. Location can also be exposed by signs, landmarks, addresses or other visible details. Metadata cleaning and visual redaction solve different problems.
