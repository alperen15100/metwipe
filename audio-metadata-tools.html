MP3 tags and WAV RIFF chunks are different

MP3Common metadata lives in tag structures such as ID3. Start at the MP3 metadata center.
WAVMetadata can live in RIFF chunks such as INFO, BEXT or iXML. Use the WAV checker for the exact file.
VerifyAfter cleaning, inspect the output again and play the file. Metadata cleanup does not remove spoken information from the audio.

Audio privacy is broader than tags

Removing supported metadata does not erase names spoken in a recording, audible watermarks, ownership rights or every proprietary metadata convention. Review the actual audio content separately before distribution.

Choose the right audio metadata workflow

MP3: start with the MP3 metadata checker when you need to inspect supported tags, or use the MP3 metadata remover for a cleaned distribution copy. WAV: use the WAV metadata checker and WAV metadata remover because RIFF chunks are structurally different from MP3 tags.

For field-level context across both formats, compare ID3 and RIFF structures in the metadata field reference. Always review the audible content separately: metadata cleanup cannot remove spoken names, voices or other information in the recording itself.
