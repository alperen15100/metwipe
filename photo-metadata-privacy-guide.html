Photo Metadata Privacy Guide

Photo privacy involves more than what you can see in an image. The underlying file may contain EXIF, GPS, timestamps and device information.

Visible content and metadata are different

Pixels contain the visible image. Metadata describes properties of the file and how, when or where it may have been produced.

Common sensitive fields

GPS coordinates, creation dates, device models, creator fields and editing software are examples worth reviewing.

Metadata removal is not anonymization

Cleaning metadata does not hide faces, addresses, reflections, documents, signs or landmarks visible in the image itself.

Use a complete privacy check

Review visible content, inspect metadata, clean an expendable copy and verify the result before sharing.

Use MetWipe

Inspect and clean supported metadata locally in your browser. MetWipe is designed so supported file processing can happen on your device rather than requiring an application-server upload.
