# MetWipe SEO Audit — 2026-10-01

## Scope
Repository-level audit of the current MetWipe static site using the imported SEO-skill methodology. Search Console data was not available in this run, so ranking/click conclusions are not claimed.

## Growth-stage assessment
MetWipe is best treated as an early/growth-stage site. The sitemap currently contains 45 indexable URLs across photo/EXIF, MP3/WAV, Office, PNG/WebP, guides, and trust pages. Coverage is useful but still materially expandable. Priority should therefore remain: working capability + distinct intent coverage + strong internal linking, before large-scale title experimentation.

## Technical baseline
Checked all 45 URLs listed in sitemap.xml.
- All 45 have a title.
- All 45 have a meta description.
- All 45 have a canonical URL.
- All 45 have exactly one H1.
- The homepage and many tool/check pages already use structured data.
- robots.txt exposes the sitemap and allows normal search crawling.
- llms.txt and agent-discovery assets already exist.

## Duplicate-intent / cannibalization candidates
These are candidates, not automatic merge decisions.

1. `remove-gps-from-jpg.html` vs `remove-location-data-from-photo.html`
   - Highest current overlap observed among sampled live pages.
   - Token-set Jaccard similarity in the repository audit sample: ~0.409.
   - Both target location/GPS removal from photos and may split similar queries.
   - Action: keep both unchanged until Search Console page+query data shows whether they serve different demand. If the same queries trigger both, choose one survivor and merge the best unique content.

2. `remove-exif.html` vs `remove-camera-info-from-photo.html`
   - Sample similarity ~0.366.
   - Likely defensible if one remains broad EXIF removal and the other is specifically camera/device fields.
   - Action: strengthen intent differentiation and monitor query overlap.

3. Word/DOCX sub-intent pages
   - `remove-docx-metadata.html` vs Author / Last Modified By / Company pages show moderate template/content overlap (~0.265–0.313 in the sample).
   - These sub-intents can remain separate because the requested field is materially different, but they need differentiated examples, explanations, and contextual links.

4. Check-photo-location vs check-EXIF
   - Lower sampled overlap (~0.232) and clearer intent separation; retain.
