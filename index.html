HOW IT WORKS

Inspect. Clean. Verify.

MetWipe is designed around the actual task rather than a fake demonstration panel. Your scan results only appear after you select your own JPEG.

1. Inspect metadata

Read common EXIF fields such as phone or camera model, timestamps, GPS, software and camera settings.

2. Remove supported metadata

Strip supported JPEG metadata segments without adding another lossy JPEG compression pass.

3. Verify the output

The generated cleaned file is scanned again before the tool reports it as verified.

FAQ

Common questions.

What is EXIF metadata?

EXIF metadata can contain camera or phone information, timestamps, camera settings and sometimes GPS coordinates inside JPEG files.

Does MetWipe upload my photo?

No. The current supported JPEG scanner and cleaner works locally in your browser.

Does metadata removal reduce JPEG quality?

The cleaner removes supported metadata segments while keeping the encoded JPEG image data, avoiding an additional image re-encode.

Is a 100/100 Privacy Score a security guarantee?

No. The score is a heuristic for supported metadata fields. Visible content can still reveal faces, addresses, documents, landmarks and other information.
