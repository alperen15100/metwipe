Choose a metadata tool

Choose the file format you actually have. Each tool uses the same local scanner with a format-specific explanation. No account or file-processing server is required. Keep an original copy and review the verification limits.

JPEG

APP1–APP15 and comment segments. Encoded JPEG scan data is retained without a new image-compression pass. Visible faces, addresses and text remain.

PNG

tEXt, zTXt, iTXt, eXIf and tIME chunks. Core image chunks are retained. Other private/unknown chunks and visible content are outside the check.

WebP

EXIF and XMP chunks. The cleaner retains encoded image chunks. Other RIFF chunks are outside its metadata-removal scope.

MP3

Leading ID3v2 and trailing ID3v1 tags. Audio is not transcribed or redacted. APE tags and other identifiers are outside the supported ID3 check.

WAV

LIST, bext, iXML, ID3, cart and DISP chunks. Audio data is retained; information spoken in it remains. LIST removal can also remove useful descriptive organization.

DOCX / XLSX / PPTX

Supported core properties, plus Company and Manager in application properties. Comments, revisions, cell values, slides, notes, custom properties, macros and embedded media are not a complete redaction target. Browser compression support is required.
