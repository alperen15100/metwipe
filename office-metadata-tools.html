Choose the right Office metadata workflow

Word / DOCX: use the deeper Word Metadata Center for checking, broad cleanup and focused Author, Last Modified By or Company properties. Excel / XLSX: inspect workbook metadata before using the XLSX remover. PowerPoint / PPTX: inspect presentation metadata before creating a copy with the PPTX remover.

The metadata field reference explains common OOXML property locations. Metadata cleanup is not document redaction: cells, slides, speaker notes, comments, tracked changes and visible text require their own review.
