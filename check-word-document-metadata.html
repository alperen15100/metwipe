WORD · DOCX CHECK

Check metadata in a Word document

A DOCX is a package of XML files, and some of those files can contain identity, organization and document-history properties that never appear on the visible page.

Quick answer

Common Word metadata includes Author, Last Modified By, Company, Manager, timestamps, revision information and custom document properties. MetWipe inspects supported OOXML properties locally so you can decide whether a clean distribution copy is needed.

Common DOCX metadata locations

Field / areaWhat it containsWhy review it
docProps/core.xmlAuthor, Last Modified By, dates and core propertiesIdentity and history information can live here.
docProps/app.xmlCompany, Manager and application propertiesCan reveal organization context.
docProps/custom.xmlCustom document propertiesMay contain internal labels, project names or workflow values.
Visible document contentNames, text, headers, comments and tracked changesThese are not made private simply because metadata properties are cleaned.

Why this specific task matters

DOCX metadata is separate from the page you see

A document can look clean while package properties still contain names or organization details.

Custom properties deserve attention

Organizations sometimes use custom fields for workflow or document-management purposes.

Metadata cleanup is not redaction

If a name appears in the text, comments, revisions, headers or embedded content, it requires a separate review.

Safe workflow

  1. Choose the DOCX copy you intend to distribute.
  2. Inspect the supported properties found by the live tool.
  3. Decide which metadata should not leave your device or organization.
  4. Create a cleaned copy, verify the rebuilt DOCX and then review the visible document content separately.

Limits to understand

This tool is not a complete Word redaction system. Comments, tracked changes, macros, embedded files, visible names and other document content can remain even after supported metadata properties are cleaned.
