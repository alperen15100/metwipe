Check metadata in a Word document

Inspect supported DOCX metadata such as author, Last Modified By, Company and custom properties locally in your browser before sharing a Word document.

Private browser workflow

Word documents can carry document properties that are not obvious from the visible page. Inspect a DOCX first, then clean a copy if the properties reveal information you do not want to share.

Open Word Metadata Tool

Inspect → clean → verify

Start by inspecting the file. Create a cleaned copy only when needed, then scan the result again to verify supported metadata. MetWipe processes supported files in the browser; review visible document or media content separately before sharing.
