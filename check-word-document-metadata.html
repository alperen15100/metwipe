WORD · DOCX CHECK

Check metadata in a Word document

A DOCX can contain document properties that never appear on the visible page. Inspect supported properties before you send a résumé, report, contract or other Word file.

Quick answer

Word DOCX metadata can include Author, Last Modified By, Company, Manager, dates, revision information and custom document properties. MetWipe inspects supported OOXML properties locally, so you can decide what needs cleaning before sharing.

Check Word Metadata

Identity fields

Author and Last Modified By can expose account or editor names.

Organization fields

Company, Manager and custom properties may reveal internal context.

Document history clues

Created, modified and revision-related fields can disclose workflow details even when the page looks clean.

How to do it safely

  1. Open the Word metadata tool.
  2. Choose the DOCX copy you intend to share.
  3. Review the supported properties found in the package.
  4. If needed, create a cleaned copy and verify the rebuilt DOCX.

What this does not cover

Metadata cleanup is not document redaction. Names in the visible text, comments, tracked changes, notes, embedded objects or other content still need a separate review.
