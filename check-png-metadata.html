Check metadata in a PNG image

PNG files can carry textual, EXIF-style and timestamp metadata chunks that are separate from the visible pixels.

Quick answer

PNG metadata may be stored in tEXt, zTXt, iTXt, eXIf or tIME chunks. Inspect the actual file before sharing because exported screenshots and edited images can still contain non-visible metadata.

Quick questions

Can a PNG contain metadata?

Yes. PNG supports multiple ancillary chunks that can carry text, EXIF-style information and timestamps.

Does removing PNG metadata change the visible image?

The metadata workflow is separate from the visible pixel content, but always verify the cleaned output before relying on it.
