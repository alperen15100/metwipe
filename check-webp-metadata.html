Check metadata in a WebP image

WebP can carry metadata chunks alongside the encoded image, including supported EXIF and XMP information.

Quick answer

A WebP file can contain EXIF or XMP metadata in addition to the image data itself. Inspect the file before publishing so camera, time, location or workflow information does not travel unintentionally.

Quick questions

Can WebP files contain EXIF metadata?

Yes. WebP supports metadata chunks, including EXIF and XMP, depending on how the image was created or exported.

Will metadata removal hide visible information?

No. Text, faces, addresses or other private information visible in the image pixels remain visible.
