WORD · AUTHOR

Remove Author metadata from a Word document

The Author property can identify the account or person associated with a DOCX even when the name is not visible in the document body.

Quick answer

MetWipe's DOCX workflow targets supported core document properties including Creator / Author. It creates a separate cleaned copy, rebuilds the DOCX package and re-opens the result for verification.

Remove Word Author Metadata

Author / Creator

The core document property can contain the creator name associated with the file.

Check related identity fields

Last Modified By, Company, Manager and custom properties may reveal additional identity or organization information.

Keep the source

Use the cleaned copy for distribution while retaining your original document privately.

How to do it safely

  1. Open the DOCX metadata remover.
  2. Select the Word file you plan to distribute.
  3. Inspect the Author and other supported properties.
  4. Create the cleaned copy, then verify the result before sharing.

What this does not cover

Removing the Author property does not remove names typed into the document, comments, tracked changes or other visible content. Review those separately.
