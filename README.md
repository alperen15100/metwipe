# MetWipe

MetWipe is a privacy-focused browser utility for inspecting, removing and verifying supported file metadata.

**Live site:** https://metwipe.com/

## Tool families

- Photo / EXIF / GPS: https://metwipe.com/photo-metadata-tools.html
- Audio / MP3 / WAV: https://metwipe.com/audio-metadata-tools.html
- Office / DOCX / XLSX / PPTX: https://metwipe.com/office-metadata-tools.html
- Metadata field reference: https://metwipe.com/metadata-field-reference.html
- Supported formats and limits: https://metwipe.com/supported-formats.html

Supported workflows are designed around local browser processing. The original file is preserved and cleaned copies are verified against the metadata structures documented for the relevant format.

## Important scope

Metadata cleanup is not the same as full redaction. Visible image details, document text, comments, tracked changes, embedded content, filenames, spoken audio and unsupported proprietary structures can remain.
