How to remove metadata from a Word document

  1. Keep your original DOCX as the source copy.
  2. Select the DOCX in the MetWipe tool above.
  3. Review the metadata fields detected before cleaning.
  4. Choose the clean-and-verify action to create a separate cleaned copy.
  5. Open the downloaded DOCX and review both its properties and visible content before sharing.

Custom document properties

DOCX files can contain custom property names and values in addition to familiar author and title fields. MetWipe's supported custom-property path has been tested with project and customer fields: the values were detected, removed from the cleaned copy and absent in the verification pass.

Cleaning metadata is not full document redaction

Comments, tracked changes, visible body text, macros, embedded media and other document content require separate review. Removing supported metadata does not automatically anonymize information that remains visibly or structurally elsewhere in the document.

Free Word metadata remover in your browser

The supported DOCX workflow is processed locally in the browser rather than requiring an application-server file upload. Browser compression support is required. For sensitive workflows, inspect the final file you actually intend to distribute.
