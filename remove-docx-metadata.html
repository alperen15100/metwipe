Where Word metadata is stored

A DOCX is an OOXML ZIP package. Common document properties live in dedicated XML parts rather than in the visible page text.

docProps/core.xml

Common core properties such as creator, last modified by, title, subject, keywords, revision and dates.

docProps/app.xml

Application and organization properties such as Company and Manager when present.

docProps/custom.xml

User-defined custom document properties that can carry internal project, customer or workflow values.

Custom document properties

DOCX files can contain custom property names and values in addition to familiar author and title fields. MetWipe's supported custom-property path has been tested with project and customer fields: the values were detected, removed from the cleaned copy and absent in the verification pass.

Cleaning metadata is not full document redaction

Comments, tracked changes, visible body text, macros, embedded media and other document content require separate review. Removing supported metadata does not automatically anonymize information that remains visibly or structurally elsewhere in the document.

Word metadata removal FAQ

How do I remove metadata from a Word document?

Select the DOCX in MetWipe, review the supported document properties, create a cleaned copy and inspect the verified output before sharing.

What metadata can a Word document contain?

A DOCX can contain properties such as Author / Creator, Last Modified By, title, subject, keywords, revision, dates, Company, Manager and custom document properties.

Does removing Word metadata remove comments and tracked changes?

No. Metadata cleanup is not full document redaction. Comments, tracked changes, visible text, macros and embedded content require separate review.
