How to remove metadata from a Word document

DOCX files can contain author names, titles, subjects, keywords, application details and timestamps that are not obvious from the visible document. MetWipe can inspect and remove supported Word document properties locally in your browser.

Remove Metadata from Word

Clean metadata from a Word DOCX file

  1. Keep the original Word document as your source copy.
  2. Open the MetWipe DOCX Metadata Remover.
  3. Select the distribution copy you intend to share.
  4. Review supported properties detected by the tool.
  5. Create the cleaned copy and inspect it again before publishing.

Which Word metadata can matter?

Document properties may contain author, title, subject, keywords and creation or modification information. The current Office workflow also targets supported core properties plus Company and Manager in application properties.

Metadata removal is not full document redaction

Comments, tracked changes, body text, cell values, slides, notes, custom properties, macros and embedded media require separate review where applicable. Removing author properties does not make the visible document anonymous.

Why use a distribution copy?

Metadata can be useful in your working document. Preserve the original and clean the copy intended for external sharing so useful source information is not unnecessarily lost.
