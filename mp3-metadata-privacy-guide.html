MP3 METADATA GUIDE

How to remove metadata from an MP3 file

MP3 files can carry metadata separately from the audio itself. MetWipe checks supported ID3, APEv2 and Lyrics3 structures, creates a cleaned copy locally in your browser and re-opens that output for verification.

Remove Metadata from MP3

Detected → Removed → Verified

The current scanner checks supported metadata structures at the beginning and end of an MP3. The cleaner preserves the bytes between those supported structures, creates a separate output and re-scans it before reporting a verified result.

Remove MP3 metadata in a browser

  1. Open the MetWipe MP3 Metadata Remover.
  2. Select the MP3 copy you plan to share.
  3. Review the supported metadata structures detected in the file.
  4. Create and download the cleaned copy.
  5. Let MetWipe re-open and verify the output, then play the downloaded copy before distribution.

Remove metadata from MP3 on Mac

MetWipe is browser-based, so there is no separate Mac installer for this workflow. Open the MP3 remover in a compatible modern browser, choose the local MP3 and process the supported metadata on-device.

What about copyright metadata?

Copyright information can be stored inside metadata, but removing a metadata field does not remove copyright ownership or grant permission to redistribute audio. Metadata cleaning and copyright status are separate issues.

Current MP3 support and limits

The current parser recognizes supported ID3v1, ID3v2, APEv2, Lyrics3v1 and Lyrics3v2 layouts. In device testing of this build, ID3v1 was detected and removed, and a cleaned fixture that still contained APEv2 and Lyrics3v2 was correctly detected; both remaining structures were then removed and the generated file passed MetWipe's local verification scan. ID3v2 and Lyrics3v1 are implemented but are not presented here as regression-verified removal claims until separate fixtures are tested. Other possible identifiers are outside this supported check.

The audio itself is not transcribed or redacted, so spoken names, voices and background clues remain. Removing metadata also does not change copyright ownership.
