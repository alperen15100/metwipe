What does the check look for?

The viewer reports supported EXIF fields found in the selected file, including GPS information when present. Not finding GPS does not prove that a place cannot be identified from the visible image itself.

How to check a photo

  1. Choose the exact JPG/JPEG file you intend to share.
  2. Open the MetWipe EXIF viewer.
  3. Inspect the reported GPS and capture fields.
  4. If privacy-relevant metadata is present, create a cleaned copy with the JPEG cleaner.
  5. Scan the cleaned copy again before sharing.

GPS metadata vs visible location clues

EXIF GPS coordinates are machine-readable metadata. Street signs, landmarks, addresses, reflections and other clues are pixels in the picture. Removing metadata does not blur or remove visible clues.

Why local inspection matters

MetWipe's supported JPEG inspection runs in your browser rather than requiring the image to be uploaded to an application server. Check the supported-formats page for exact limitations.

Which EXIF fields can indicate a stored location?

A GPS-enabled JPEG can contain several related EXIF fields rather than one human-readable address. Common examples include latitude and longitude values plus north/south and east/west reference fields. Some files may also include altitude or GPS timestamps. MetWipe reports supported GPS-related fields when they are present so you can review the actual file instead of assuming that every phone photo contains location data.

If no GPS metadata is found

A clean GPS check means the supported location fields were not found in the inspected file; it does not prove the image is anonymous. A visible street name, landmark, house number, school logo or other scene detail can still identify a place. Treat metadata inspection and visual privacy review as two separate steps.

Checker or remover?

Use the checker when you only need to know whether supported GPS fields are present. If the scan finds location or other EXIF details you do not want to distribute, use the JPEG EXIF remover to create a separate cleaned copy, then inspect that output again.

Photo GPS metadata questions

Can a phone photo contain coordinates? It can when location data was recorded and preserved through later editing or sharing. The only reliable way to know for a particular file is to inspect that file.

Can I find an address from EXIF? EXIF may contain coordinates rather than a street address. MetWipe reports supported file metadata; it does not turn coordinates into a claim about who took the photo or who was at that location.
