Remove GPS metadata from a JPG photo

A JPG can contain latitude and longitude inside EXIF metadata. Remove supported GPS fields before sharing when the capture location should remain private.

Quick answer

GPS metadata is separate from the visible image. MetWipe can inspect supported photo metadata, create a cleaned copy and let you verify the output before distribution.

Remove GPS Metadata

Latitude & longitude

Coordinates can point to the place where the photo was captured.

Location is not visible

A photo may look harmless while still carrying GPS metadata in the file.

Clean the copy you share

Keep the original privately if you need its location history, and distribute the cleaned copy instead.

How to do it safely

  1. Check the photo for location metadata.
  2. Open the EXIF remover when GPS fields are present.
  3. Create a cleaned JPG copy.
  4. Verify the output before posting or sending it.

What this does not cover

Removing GPS metadata does not hide a recognizable location visible in the photo itself. Landmarks, street signs and other visual clues remain.
