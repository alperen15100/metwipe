How we write, test and correct guides

MetWipe is published by Ecrin Labs. Its guides explain how supported local metadata tools behave and how to check a downloaded copy. We do not publish invented customer outcomes, security certifications or claims that a file becomes untraceable.

Implementation and examples

Descriptions of supported formats are based on the current source code. Worked examples use non-sensitive synthetic files or clearly labeled scenarios. This update was prepared with AI assistance and checked against the implementation. It is not an independent security assessment.

Sources

We distinguish the file-format specification from what this tool implements. A format can contain fields the scanner does not display or remove. Read the supported-formats table before relying on a guide. Primary references include the PNG specification, WebP container documentation and ID3v2.4 structure specification.

Corrections

Email ecrincrypto@gmail.com with the page address, browser version, file format and expected versus observed result. Start with a description or a non-sensitive reproduction; do not send private documents or audio. A page update date indicates an edit, not continuous verification.

Advertising

MetWipe is free to use and has an AdSense integration. Advertising availability depends on approval and configuration. Advertisements are separate from tool controls and do not establish that an advertised product is endorsed. File cleaning does not require an ad click.
