# MetWipe Backlink Outreach

Use this skill for link building, directory submissions, tool-list outreach, launch listings and external discovery work for MetWipe.

## Objective
Earn relevant, legitimate external links and referral traffic without link spam.

## Mandatory rules
1. Prefer relevance over raw domain metrics.
2. Never claim a listing, backlink or PR is live until the public URL is verified.
3. Do not buy backlinks solely for ranking manipulation.
4. Do not mass-submit to unrelated directories.
5. Do not submit MetWipe to AI-only directories; MetWipe is not an AI product.
6. Do not pitch strict no-ads/no-tracking privacy lists while MetWipe uses advertising scripts.
7. Do not add reciprocal badges to the production footer solely to obtain a backlink without a clear strategic reason.
8. Keep all submission claims aligned with current supported formats and local-processing behavior.
9. Never claim PDF, HEIC, FLAC, M4A, MP4/MOV or other unsupported capabilities until implemented and verified.
10. Separate file-processing privacy from website third-party scripts: supported files are processed locally, but this is not the same as saying the website has no third-party scripts.

## Preferred targets
Priority order:
1. Curated browser-tool / developer-tool lists that explicitly accept contributions.
2. Reputable software or web-tool directories with free organic review.
3. Relevant privacy/security resource pages whose criteria MetWipe actually satisfies.
4. Editorial roundups and citations to MetWipe's useful reference content.
5. Community launches where the product is genuinely relevant.

MetWipe — Free browser-based metadata privacy tools for checking and removing supported EXIF/GPS, MP3/WAV and Office metadata locally, with post-clean verification.

## Workflow
1. Verify the target is live and currently accepts submissions/contributions.
2. Read its inclusion rules.
3. Confirm MetWipe meets them.
4. Check for an existing MetWipe listing/request to avoid duplicates.
5. Use the shortest factual description that fits the target.
6. Submit only through the target's preferred channel.
7. Record the submission and date in the backlink campaign file.
8. Recheck later and mark LIVE only with a verified public URL.
