Remove PNG metadata locally

PNG files can contain textual metadata, timestamps and EXIF-style chunks. MetWipe can remove supported metadata chunks while preserving the core PNG image chunks and pixel data.

Local processing

Supported files are processed in the browser rather than uploaded to an application file server.

Verification

MetWipe re-inspects the generated output before reporting supported metadata as removed.

Original preserved

The original file is not overwritten. A separate cleaned copy is generated.
